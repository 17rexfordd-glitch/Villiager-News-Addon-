# Source Code

The current NeoForge 1.21.1 source package for the randomized 1.3.4 build is stored alongside this repository documentation.

Target environment:
- Minecraft 1.21.1
- NeoForge 21.1.248
- Java 21
- EMF 3.3.5
- ETF 7.2.1
- ESF 0.8.2

The source package contains all 29 Java source files plus the NeoForge mod metadata and mixin configuration files for the tested randomized 1.3.4 build.
